# Public Assets

Ce dossier contient tous les assets statiques du site web CGEK.

## Structure des dossiers

### 📁 images/
- **hero/** - Images pour la section hero/bannière
- **services/** - Images liées aux services médicaux
- **team/** - Photos de l'équipe médicale
- **gallery/** - Galerie d'images de la clinique
- **background/** - Images d'arrière-plan

### 📁 icons/
- **favicon.ico** - Icône du site
- **logo/** - Logos de la clinique en différents formats
- **social/** - Icônes des réseaux sociaux

### 📁 documents/
- **brochures/** - Brochures médicales en PDF
- **forms/** - Formulaires téléchargeables
- **certificates/** - Certificats et accréditations

## Notes importantes

- Tous les fichiers dans ce dossier sont accessibles publiquement
- Optimisez les images avant de les ajouter (format WebP recommandé)
- Utilisez des noms de fichiers descriptifs et en minuscules
- Évitez les espaces dans les noms de fichiers (utilisez des tirets)
